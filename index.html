Konfigurasi Split Server & Koneksi Database SIK

Aplikasi ini menggunakan arsitektur split server lintas sistem operasi (Windows untuk Web Server, Linux untuk Database MySQL SIK) sesuai dokumen spesifikasi PRD v1.2.

Web Server (Aplikasi)
  • IP Address: 192.168.1.36
  • Sistem Operasi: Windows
  • Environment: XAMPP (Apache)
  • Versi PHP: PHP 8.2 (PDO MySQL)
  • Peran: Antarmuka, Filter, dan Client-side Exporter
Database Server (SIK)
  • IP Address: 192.168.1.2
  • Port MySQL: 3306
  • Nama Database: sik
  • User Akun (NF.01): report_viewer (Read-Only)
  • Akses Privileges: GRANT SELECT ON sik.*
Uji Status Koneksi Port 3306
Kirimkan request ping PDO ke 192.168.1.2:3306/sik
Keamanan Sesuai PRD (NF.01):
Koneksi dari Web Server tidak menggunakan user root. Query dijamin 100% Read-Only (SELECT) tanpa adanya operasi manipulasi data (Create, Update, Delete).
Panduan Ekstraksi & Ekspor Laporan SIK
1. Cara Melakukan Filter Data (F1.01)

Pilih Tanggal Mulai dan Tanggal Akhir yang diinginkan, kemudian tentukan Kategori/Unit (misalnya: Radiologi, Rawat Jalan, dsb). Klik tombol "Tampilkan Data" untuk mengirim query ke database server.

2. Fitur Pencarian Cepat & Pengurutan (F2.02 & F2.03)

Ketik nama pasien, nomor rawat, nama dokter, atau tindakan pada kolom "Cari data instan..." di atas tabel. Data akan tersaring secara otomatis seketika. Klik judul kolom mana pun untuk mengurutkan (A-Z atau tanggal terbaru).

3. Opsi Ekspor Laporan (F3.01 - F3.03 & NF.02)
Copy: Salin seluruh data yang tampil untuk langsung ditempel (*paste*) ke Microsoft Excel.
CSV: Unduh data dalam format CSV standar (UTF-8 BOM).
Excel: Unduh file lembar kerja Excel (.xlsx/.xls) dengan kop dan tabel rapi.
PDF: Buka jendela pratinjau dokumen cetak A4 landscape dengan kop surat resmi.
